# Arthritis tracker

A private, offline-first tracker for arthritis blood reports, medicines and everyday care, in English and Hindi, with light and dark modes.

- Compares the 3 newest reports, with charts, a ranked "needs attention" list and plain-language explanations.
- Medicines section: long-term effects, warnings, and checks of the blood tests each medicine needs.
- Natural-help suggestions that reorder themselves with every new report.
- Data stays in the browser. You can download a backup file, or add an optional Supabase cloud backup locked to your own sign-in.

**Start with [GUIDE.md](GUIDE.md)** for publishing on GitHub Pages and setting up the Supabase backup.

Plain HTML, CSS and JavaScript with no build step. Open `index.html` directly, or host the folder on any static host.

Not medical advice. Her doctor decides treatment.

**Never commit real health data to this repository.**
